# ELEC5305 Project Proposal

## Project Title
Speech Noise Reduction Using STFT and Wiener Filtering

## Project Overview
This project aims to reduce background noise in speech signals using Short-Time Fourier Transform (STFT) and Wiener filtering.

The noisy speech signal will first be transformed into the time-frequency domain using STFT. Wiener filtering will then be applied to suppress background noise, and the enhanced speech signal will be reconstructed using inverse STFT.

The performance of the system will be evaluated by comparing the noisy and enhanced speech signals using signal-to-noise ratio (SNR), waveforms, and spectrograms.

## Tools and Methods
- MATLAB or Python
- Short-Time Fourier Transform (STFT)
- Wiener Filtering
- Inverse STFT
- Signal-to-Noise Ratio (SNR) evaluation
